## MINIMUM SPECS FOR AI VIBE CODING

| Component | Minimum | Recommended | Why |
|-----------|---------|-------------|-----|
| **CPU** | Intel i7-14th Gen / AMD Ryzen 7 7700 | Intel Core Ultra 7 265F / AMD Ryzen 7 9800X3D | Multi-threaded for running IDE + AI tools + browser simultaneously |
| **GPU** | RTX 5060 (8GB VRAM) | RTX 5070 (12GB VRAM) or RTX 5070 Ti (16GB VRAM) | Local LLM inference, GPU-accelerated coding tools, future-proofing |
| **RAM** | 32GB DDR5 | 32–64GB DDR5 | Cursor + Claude Code + browser + multiple dev servers eat RAM fast |
| **Storage** | 1TB NVMe SSD | 2TB NVMe SSD | Projects, node_modules, Docker images, AI models fill up fast |
| **PSU** | 650W | 850W+ Gold | Headroom for GPU power spikes |
| **WiFi** | WiFi 6 | WiFi 6E / WiFi 7 | Fast, stable internet is critical for cloud-based AI APIs |
