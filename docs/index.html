Compatibility Confirmed — Buy DDR4-3200 (auto-downclocks to 2666MHz)

Your HP needs DDR4 UDIMM, 288-pin, Non-ECC, 1.2V. Max 32GB across 2 slots. DDR4-3200 costs the same as DDR4-2666 (~$240-260) but gives you better specs if you reuse the RAM later. Remove BOTH old sticks and install a matched 2x16GB kit.
